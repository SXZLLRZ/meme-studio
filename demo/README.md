# 合成演示素材

这些素材用于说明本项目的导入、区域编辑、配字和静态到动态流程，不包含个人图库图片。

| 文件 | 来源与用途 |
| --- | --- |
| `gallery/source.png` | 程序绘制的米色背景红色圆形，默认图库的导入示例 |
| `media/p4-mask.png` | 上述原图的二值编辑蒙版，白色为编辑区域 |
| `media/p4-static.png` | P4 已完成的真实局部编辑结果 |
| `media/static-caption.png` | 在静态结果上由本机渲染文字的示例 |
| `media/p7-live-caption.mp4` | P7 从同一静态结果真实生成视频，再由本机配字导出的历史 MP4 |
| `media/p7-live-caption.gif` | 同一视频经本机导出的普通循环 GIF |

先将 `gallery/source.png` 导入图库，可在本机进行框选、画笔、配字和 PNG 导出。中文检索与 SAM 需要按安装说明准备相应模型。

打开 `media` 中的文件是历史产物回放，不代表正在实时生成。静态图片为 1024×1024；MP4 为 960×960、3 秒、30 fps、H.264、无音轨；GIF 为 512×512、36 帧、约 3.01 秒。它们用于功能核验，不作为生成效果的统计评测。

第三方软件与模型来源见 [第三方与素材说明](../docs/第三方与素材.md)。
