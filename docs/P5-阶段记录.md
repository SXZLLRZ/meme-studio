
# P5 点选辅助、合并指令与多轮约束

## 使用和复测

1. 双击项目目录里的 start.cmd。打开「图库与检索 → 合并指令」，本机拆解「找戴墨镜的橘猫」和「找一张橘猫，给它加墨镜」。前一句把墨镜留在检索描述，后一句把加墨镜放入编辑要求。两个框都可修改。检索和选图后，点击「用所选图创建编辑项目」把要求带入静态生成草稿。
2. 在「编辑与历史 → 局部选区 → SAM 点选主体」点主体作为正点，切换负点标出背景。也可用两个角指定提示框。点「生成本地蒙版候选」，查看红色覆盖，选择并保存。用「画笔与橡皮」修边后保存修正版。
3. 在「保留要求」新增一条目标为「背景」的持续要求，例如「背景保持不变」。到「静态生成」预览「眼泪再大一点」，再预览「背景完全不变并换成海边」，应分别显示背景要求和冲突提示。「把背景换成蓝色」应显示这轮采用新说明，成功后移除旧静态保护。
4. 「历史与导出」可撤销、恢复和导出 PNG。打开生成版本可看实际发送的提示词。以上检查可用本机拆解和请求预览完成。

「云端拆解文字」为显式操作，可能产生一次文字费用。它发送用户原句、页面、选图状态、版本类型与适用的要求，返回可修改的草稿。结构化响应无效、连接超时或平台拒绝时，本机回退并保留原输入。支持的文字服务地址为中国内地 DashScope 兼容接口。

## 模型与环境

- SAM 2.1 Hiera Tiny 来自 [Meta 官方源码的固定提交](https://github.com/facebookresearch/sam2/tree/2b90b9f5ceec907a1c18123530e92e794ad901a4)，安装包版本 SAM-2 1.0。配置 configs/sam2.1/sam2.1_hiera_t.yaml。
- 官方 [SAM 2.1 Tiny 权重](https://dl.fbaipublicfiles.com/segment_anything_2/092824/sam2.1_hiera_tiny.pt) 放在 models/sam2/sam2.1_hiera_tiny.pt，本地 SHA-256 为 7402e0d864fa82708a20fbd15bc84245c2f26dff0eb43a4b5b93452deb34be69。
- 依据 [官方安装说明](https://github.com/facebookresearch/sam2/blob/2b90b9f5ceec907a1c18123530e92e794ad901a4/INSTALL.md)，本机禁用可选 CUDA 后处理扩展的编译。原生 Windows 上的模型推理实际走 RTX 4060 Laptop GPU，PyTorch 2.8.0+cu128 和 torchvision 0.23.0+cu128。需要重装时，先按 README 安装 PyTorch，再在项目虚拟环境安装 hydra-core==1.3.2、iopath==0.1.10、wheel，当前 PowerShell 设置 $env:SAM2_BUILD_CUDA='0'，用 pip install --no-build-isolation --no-deps 安装上述提交的官方源码目录。
- SAM 和 Chinese-CLIP 共享推理锁并轮换驻留。实际测得检索和 SAM 的 PyTorch 峰值已分配显存约 384 MiB 和 598 MiB，SAM 进程分配器峰值保留约 824 MiB。连续在同一底图加点可复用编码。切换项目会重编码，切到另一模型会释放旧模型，下次使用时重载。实测记录在 runtime/p5-gpu-check.json。
- 底图预览沿用 P3 坐标和缩放。SAM 推理使用无字底图，输出先在预览尺寸核对，保存时以最近邻还原为原图尺寸的单通道二值 PNG。画笔工具可载入候选蒙版并继续修正。候选绑定项目、版本、底图和哈希。

## 约束规则

每项要求保存类别、目标、内容、作用域、持续时间及来源版本。相同目标的新条目替换旧条目。单次画面要求在对应生成成功后消耗，失败可按原版本重试。配字要求作为排版提示，一次性条目在成功保存新文案后消耗。动态作用域随版本保存，动态流程由 P6 接入。

静态修改明确覆盖同一目标时，旧静态要求退出本轮提示词，且在成功结果版本中移除。兼用于动态的旧要求保留动态作用域。新的修改说明只用于这次任务。需要持续采用新的设置时，可在「保留要求」保存为持续条目。文字冲突校验覆盖能够识别的明确中文改动和保护表达，复杂语义可在预览时核对。画面要求由模型尽力遵循，固定选区外像素由 P4 的局部合成实现。

本机使用现有数据库的版本字段，数据库结构版本仍为 4。既有项目和历史可直接使用。

## 验收

- 26 项离线测试通过，包含结构化校验与回退、单次约束消费、失败保留、历史恢复、候选蒙版与修正。测试中用 HTTP 模拟服务代替云端调用。
- 本机页面验证覆盖拆解、选图、草稿传递、真实 SAM 候选和蒙版保存、冲突与替换预览、撤销和 PNG 导出。见 runtime/p5-ui-check.json。
- 单次真实 Qwen-Plus 文字调用收到响应，但未通过本机校验。示例的正确拆分来自本机回退。P7 使用修改后的结构化提示词单次复测通过，记录于 P7 阶段。证据见 runtime/p5-text-live.json。
- 首次测试只记录了错误类型。后续版本提供完整 JSON 示例，并按响应大小、外层格式、完成状态和字段校验记录回退原因。接口参照 [阿里云百炼结构化输出文档](https://www.alibabacloud.com/help/zh/model-studio/qwen-structured-output)。
