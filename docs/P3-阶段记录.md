# P3 本地状态、文字层、框选与涂抹

日期 2026-11-10。按原开发清单完成 P3-01 至 P3-17。生成 API 新增请求为文字 0、图片 0、视频 0。

## 使用

1. 在原项目目录运行 `start.cmd`。进入「图库与检索」，点击一张已导入的图片，再点「用所选图创建编辑项目」。已有项目可从「编辑与历史」的下拉菜单打开。
2. 在「本地配字」填写文案，调整字号、横纵位置、颜色及描边。点「预览配字」可先检查效果，再点「保存文字版本」。留空并保存可隐藏文字。
3. 在「局部选区」使用「两角框选」，在无字底图上点击两个对角。也可切换「画笔与橡皮」，增减笔画后点击「保存涂抹选区」。点击「整图 / 清空选区」可回到无蒙版状态。
4. 在「历史与导出」撤销到父版本，或选中一条记录后点「恢复所选版本」。在旧版本上保存会从该版本产生新分支。点击「导出 PNG」，在「PNG 下载」中保存文件。

底图保持原尺寸。交互画布最长边为 1024 像素，矩形和笔画按对应比例保存为原尺寸二值蒙版。PNG 导出在原尺寸渲染当前文字层。红色选区是单独的编辑提示。

## 字体

默认按可用字形查找 Windows 自带的微软雅黑、黑体等字体。可在项目设置填写 editor_font，或设置 MEME_STUDIO_FONT_PATH 为本机字体路径。项目引用系统字体。若文案中的字符找不到字形，界面会列出需要替换的字符。
