# P2 图库导入、缓存与中文检索

日期 2026-11-10。按原开发规格从 P1 独立实现，范围 P2-01 至 P2-20。生成 API 新增请求为文字 0、图片 0、视频 0。

## 使用和测试

1. 在项目目录双击 `start.cmd`，或在 PowerShell 运行同一命令。
2. 在「图库与检索」选择默认图库，目录默认是桌面「测试」。可改目录，也可多选 JPEG、PNG、WEBP、BMP 文件上传到本机应用。
3. 点击「导入目录」或「导入已选文件」，查看新增、重复、失败与新增编码数。默认上限每张 24 MiB、2400 万像素，可在 `settings.json` 的 gallery_limits 调整。
4. 输入描述画面的中文，点击「中文检索」。点击结果卡片会显示稳定图片 ID。候选数默认 6。余弦分数用于排序。
5. 用「保存标签」录入逗号分隔的标签，再选择「标签过滤」。用「新建图库」创建另一册。移出图片仅取消当前图库关联，项目保留图片副本和历史引用。
6. 同一图库重复导入，预期新增编码 0。关闭服务再启动，查看索引仍可用。若提示索引损坏，点「更新/重建索引」。缺少模型或索引时可用「浏览全部」。

在项目目录运行全部离线测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 模型来源与重建

- 推理包为 cn-clip 1.6.0，源码来自 [Chinese-CLIP 官方仓库](https://github.com/OFA-Sys/Chinese-CLIP)，发布包见 [PyPI](https://pypi.org/project/cn-clip/1.6.0/)。
- ViT-B/16 检查点为 `models/clip_cn_vit-b-16.pt`，大小 753196934 字节。下载来自 [项目发布方在 ModelScope 上列出的模型仓库](https://www.modelscope.cn/models/AI-ModelScope/chinese-clip-vit-base-patch16)，校验依据为 [OFA-Sys 发布文件的 SHA-256](https://huggingface.co/OFA-Sys/chinese-clip-vit-base-patch16/blob/main/clip_cn_vit-b-16.pt)。
- SHA-256 为 `5997ef32c50de18f3ac06eb5d746c324a639053c3bed8f2986f97ebb22b2ecde`。
- 当前电脑已安装以下依赖及权重。换环境时先恢复 README 的 P1 环境，再安装推理包：

```powershell
.\.venv\Scripts\python.exe -m pip install "six>=1.16,<2"
.\.venv\Scripts\python.exe -m pip install --no-deps "cn-clip==1.6.0"
```

然后在上面的发布仓库获取 clip_cn_vit-b-16.pt，放到项目的 models 目录。程序在加载前核对 SHA-256。官方包还声明了训练侧依赖 timm 和 lmdb==1.3.0，当前使用仅推理安装，pip check 会提示这两项训练依赖。
