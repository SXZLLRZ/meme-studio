# P4 静态编辑、任务恢复与结果下载

日期 2026-11-10。P4-01 至 P4-20 已验收。经单次授权，完成一次真实蒙版生成，平台报告生成 1 张。

## 使用

1. 在原项目目录运行 `start.cmd`。用图库照片创建编辑项目，或打开已有项目。
2. 整图修改可直接进入「编辑与历史 → 静态生成」。局部修改先到「局部选区」保存框选或涂抹，再回到「静态生成」，选择「使用已保存选区」。
3. 填写修改说明。局部可勾选「保留选区外原像素」。点击「提交 1 张（可能计费）」会发送当前无字底图，局部模式还会发送蒙版。已配置的本机 Key 由后端读取。
4. 在任务区查看本机和平台状态。「停止等待」只暂停本机后续查询，已经提交的云端任务可能继续运行。用「继续查询」恢复原任务。若显示「提交未知」，先按平台控制台核对。
5. 出现「结果已保存」后，点「查看结果」或「打开结果版本」。生成结果属于提交时的版本，在其他版本工作时会加入历史。原文字设置随结果保存，进入「历史与导出」可以下载 PNG。

像素保护默认关闭。打开后，只有返回尺寸与发送副本一致才按记录逆映射并保留选区外原像素。发送副本最长边上限为 1536，必要时补白到接口要求的 512 像素最短边，蒙版的补边为黑色。无保护且尺寸不一致时保留返回尺寸。

## 本地验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

19 项离线测试包括断线响应丢失、401/403 权限、余额不足、429/5xx、双击、重启、查询退避、等待超时、暂停竞态、结果损坏、链接过期、尺寸不匹配、跨版本结果归属、去重计费记录、无字底图和选区外像素比较。P4 的模拟服务只在验收中注入。价格字段缺失时显示「待配置」。

升级前的 SQLite 备份保存在 `runtime/p4-before-migration.sqlite3`。应用数据模式为 4。任务冻结副本在 `runtime/jobs/` 内，包含可复核的指令、版本、变换和图像哈希。密钥由现有本机配置读取，任务状态界面不显示签名下载地址或图像 Base64。

模型和接口参数见 [千问万相 2.1 图像编辑说明](https://platform.qianwenai.com/docs/developer-guides/image-generation/wan21-image-editing) 和 [异步提交与查询参考](https://www.alibabacloud.com/help/en/model-studio/wanx-image-edit-api-reference)。项目继续使用 P0 实测的国内媒体地址与模型。
