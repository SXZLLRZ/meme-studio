
# 第三方与素材说明

| 组件 | 来源与归属 | 交付方式 |
| --- | --- | --- |
| Chinese-CLIP | OFA-Sys 官方仓库采用 MIT。检查点按发布页获取并校验。 | 源码包提供下载位置和哈希。 [官方仓库](https://github.com/OFA-Sys/Chinese-CLIP) |
| SAM 2 | Meta 官方仓库采用 Apache 2.0。使用 SAM 2.1 Tiny。 | 依赖和权重按固定来源获取。 [SAM 2 许可证](https://github.com/facebookresearch/sam2/blob/main/LICENSE) |
| Gradio | Gradio 官方仓库采用 Apache 2.0。 | 从 PyPI 安装锁定版本。 [Gradio 许可证](https://github.com/gradio-app/gradio/blob/main/LICENSE) |
| FFmpeg 与 libx264 | 本机使用外置构建。具体许可随编译选项和发布构建。 | 二进制单独安装，参考构建发布方的许可。 [FFmpeg Windows 构建](https://www.gyan.dev/ffmpeg/builds/) |
| Windows 系统字体 | 使用系统已安装字体渲染像素文字。 | 提交包中的示例只包含渲染结果。 [Microsoft 字体说明](https://learn.microsoft.com/en-us/typography/fonts/font-faq) |
| 云端模型 | 百炼 Qwen-Plus、万相图片编辑、万相图生视频。 | 由使用方用自己的帐号配置。 [百炼文档](https://www.alibabacloud.com/help/zh/model-studio/) |

样例原图为程序绘制的几何图形。P4 静态结果来自该合成图的真实蒙版编辑。示例 PNG 配字由本机渲染。若包内含 P7 视频和 GIF，来源是同一合成图静态结果的 P7 实测。个人图库、P0 私人原图与其生成视频属于本机验收数据。
