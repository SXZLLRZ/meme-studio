
# Windows 安装与复现

源码包以 Windows x64、Python 3.11 为基线。用 Python 官方安装器装好 3.11 后，在解压出的项目目录运行以下命令。

~~~powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe -m pip check
.\start.cmd --check
.\start.cmd
~~~

可直接浏览和导入 demo/gallery 的合成示例，并用框选、画笔、配字、历史与 PNG 导出。需要实际搜索、点选主体和视频处理时再安装对应依赖。源码入口从 src 加载应用。

## 本地模型与视频工具

~~~powershell
.\.venv\Scripts\python.exe -m pip install -c requirements.lock -r requirements-models.lock
.\.venv\Scripts\python.exe -m pip install --no-deps --index-url https://download.pytorch.org/whl/cu128 torch==2.8.0+cu128 torchvision==0.23.0+cu128
.\.venv\Scripts\python.exe -m pip install --no-deps cn-clip==1.6.0
$env:SAM2_BUILD_CUDA='0'
.\.venv\Scripts\python.exe -m pip install --no-deps --no-build-isolation https://github.com/facebookresearch/sam2/archive/2b90b9f5ceec907a1c18123530e92e794ad901a4.zip
~~~

Chinese-CLIP 在本项目只用于推理。其发布包另声明训练依赖 timm、lmdb，采用上述安装方式时，安装后的 pip check 会提示这两项。基础依赖在独立环境中的 pip check 单独通过。使用适配 CUDA 12.8 的 NVIDIA 驱动，或根据 [PyTorch 官方历史版本](https://pytorch.org/get-started/previous-versions/#v280) 选择匹配的 CPU 轮子。SAM 的可选后处理扩展关闭，模型仍可使用 PyTorch CUDA 推理。

从 [FFmpeg 下载页](https://ffmpeg.org/download.html) 选择 Windows 构建，将 ffmpeg.exe 和 ffprobe.exe 放到 runtime/ffmpeg/bin，或用 PATH 指向本机的程序。检查输出应有 h264_libx264 为 true。用 start.cmd --check --gpu 测试 CUDA，再运行完整单元测试。视频工具缺席时，视频编解码相关测试会标记为跳过。

运行云端任务前，把 .env.example 复制为本地 .env 并填自己的通用千问密钥。默认输出一张图或一段 3 秒无声视频。按页面的显式提交按钮才开始云端任务。

## 备份、清理与换机

1. 停止本机应用，确保没有写入中的任务，然后整体复制运行目录。至少保存 app.sqlite3、assets、thumbnails、indexes、jobs 和 exports，维持相对结构。数据库和媒体文件属于同一份备份。
2. 把备份恢复到新机器的项目内，再设置 MEME_STUDIO_RUNTIME_DIR。原图库目录可在界面或 MEME_STUDIO_GALLERY_DIR 调整。原目录移动后，既有项目仍通过已保存资产读图。
3. 停服后可清理 gradio-cache 和 video-work 的临时文件。持久资产、任务副本和导出应由引用关系判断是否还需要。原图库文件由用户管理。
4. 字体优先使用可用的本机系统字体。需要指定字体时使用 MEME_STUDIO_FONT_PATH，并在新电脑重新核对中文字体。
