
# 演示与答辩提纲

## 建议演示顺序

1. 打开项目首页，导入 demo/gallery 内的合成图。模型已就绪时搜索「米色背景中间的红色圆形」。展示搜索结果中的稳定图片 ID，并说明第二次导入可复用索引。
2. 打开「合并指令」，先用本机拆解「找戴墨镜的橘猫」和「找一张橘猫，给它加墨镜」。第一句要求搜索已有墨镜，第二句的墨镜属于编辑任务。可现场改草稿。
3. 用合成图创建项目，做一次框选或 SAM 点选，查看红色预览，再用画笔修边。打开 demo/media 中标明 P4 来源的蒙版和静态结果。讲解固定选区外像素的条件。
4. 在本地配字保存两次，撤销并恢复旧版本，证明换字只改本机文字层。导出一张 PNG。
5. 讲解「动态与导出」的静态锚点、动作描述、任务恢复和视频配字。如果播放事先生成的文件，屏幕上标明「历史产物回放」。仅在现场获得同意、且时间与额度允许时明确提交云任务。改字和导出可以使用已有视频版本。
6. 展示正常完成、等待和失败的状态。结束时说明真实请求、模拟测试和历史回放各自验证的范围。

## 常见问题

- **哪里体现课程工作？** 关键工作是把个人图库检索、意图拆分、选区与版本化生成串成可回溯的流程。采用预训练模型和云服务完成推理。
- **接口记得历史吗？** SQLite 保存底图、选区、文字与约束。每次提交冻结请求，后续在同一任务 ID 上继续查询。
- **背景真的不会动吗？** 静态局部合成在结果可对齐时能保持选区外像素。语言保护由模型尽力遵循。视频基于静态首帧生成。
- **费用怎么控制？** 提交动作显式触发。查询或下载出错时按原 ID 恢复。只改文字使用原资产，重复导出命中缓存。
- **实验结论是什么？** 演示样本证明这些操作可以联通。课程未指定独立检索对比时，只报告功能核验，保留模型泛化效果为进一步评估。
