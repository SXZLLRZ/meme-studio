
# 个人图库表情包工作台

## 课程项目报告

### 背景与目标

个人图库里能找到一张合适的照片，还需要保留主体、修改画面、配置文字，再导出为静态或动态表情包。本系统把中文检索、区域选择、静态生成、动态生成和本地文字层放在同一份版本历史里，便于继续修改和恢复。应用定位为 Windows 单用户本地运行。

### 流程与模块

~~~mermaid
flowchart LR
    A[本机图库] --> B[中文检索与选图]
    B --> C[无字底图与选区]
    C --> D[静态编辑任务]
    D --> E[静态结果版本]
    E --> F[首帧图生视频任务]
    E --> G[本机配字与 PNG]
    F --> H[无字视频版本]
    H --> I[本机配字与 MP4/GIF]
~~~

图库模块把规范化图片与稳定 ID 存入本机目录，以预处理版本、模型和文件哈希管理向量缓存。Chinese-CLIP 编码图像和中文查询，用余弦相似度排序。合并指令模块把检索描述和编辑要求拆成两个可修改草稿。SAM 的正负点与框提示可生成候选蒙版，候选保存后可涂抹修正。

SQLite 管理项目、不可变版本、资产、选区、任务、用量和导出。每个版本记录父版本、当前底图、文字层和保留要求。图片生成时冻结输入、蒙版与提示词，结果保存后按来源版本更新指针。动态版记录静态锚点，改动作从锚点重新生成，改字沿用当前无字视频。FFmpeg 按实测尺寸叠加透明文字层，导出 H.264 MP4 和普通循环 GIF。相同版本与参数复用导出缓存。

### 资源、用量和失败

当前电脑为 RTX 4060 Laptop，约 8 GiB 显存。Chinese-CLIP 与 SAM 轮换使用 GPU。P5 样例实测 PyTorch 峰值已分配显存分别约 384 MiB、598 MiB。P7 三张合成图的索引加一次检索实测约 7.4 秒，含首次加载，作为当次记录。P4 蒙版任务由本机建任务到保存约 14.9 秒。两次耗时受素材、首次加载与平台排队影响。

| 阶段 | 已记录的真实请求或用量 |
| --- | --- |
| P0 | 文字测试 14 Token，整图 1 张，720P 无声视频 3 秒 |
| P4 | 局部蒙版图片 1 张，本机与平台状态均完成 |
| P5 | 结构化文字请求 1 次，返回后校验失败并回退，本轮 Token 未记录 |
| P6 | 取回 P0 历史视频，新增模型生成 0 次 |
| P7 | Qwen-Plus 文字 1 次通过，静态图片 0 次，720P 无声视频 1 段、平台计量 3 秒 |

实际账单、单价和部分早期耗时缺失。模拟流程中的用量和耗时不计入真实记录。P5 首次错误只记录到校验异常类型。补齐完整 JSON 样例和错误分类后，P7 云端返回检索「橘猫」和编辑「给它加墨镜」。

### 真实静态到动态实测

P7 使用程序绘制的合成图。真实静态结果沿用 P4 的历史版本，本轮无需再次提交图片。P7 真实视频任务从本机建任务到成功保存约 22.1 秒，已包含本机排队、查询和下载。任务对象重开后恢复同一平台 ID。视频配字使用原无字视频，生成任务数保持一段。

| 导出 | 实际检查 |
| --- | --- |
| PNG | 1024×1024，已解码 |
| MP4 | 960×960，3 秒，30 fps，90 帧，H.264，无音轨 |
| GIF | 512×512，36 帧，约 3.01 秒，约 1.79 MiB，普通循环 |

### 课程贡献与限制

实现重点是把检索意图和编辑意图区分，再将底图、区域、文字和多轮要求绑到可复用的历史版本。三图检索用于功能核验。暂无预先冻结的对比查询及人工相关集合，暂不报告 Hit@K 或 Recall@K 的对照结论。自然语言冲突识别覆盖常见明确表达。视频从静态首帧生成，普通 GIF 循环保留原动作节奏及可见接缝。

用户提供任务规格、阶段复测与付费请求授权。Codex 完成该版本的实现、测试和交付整理。课程成员姓名、实际分工、汇报时长按提交者的真实情况填写。

### 引用与安装

- 中文图文检索采用 [Chinese-CLIP 官方实现](https://github.com/OFA-Sys/Chinese-CLIP)。
- 提示式分割采用 [Meta SAM 2](https://github.com/facebookresearch/sam2)。
- 图像和视频任务使用 [阿里云百炼接口](https://www.alibabacloud.com/help/zh/model-studio/)。
- 视频文字叠加及 GIF 调色板参考 [FFmpeg Filters](https://ffmpeg.org/ffmpeg-filters.html)。
- 软件安装、演示与数据备份见源码包内的《安装复现》和《演示与答辩》。
