## 提交与使用

仓库中的 `README.md` 是安装和操作入口；`docs/课程报告.md` 是项目技术说明。课程组别、姓名、学号及实际分工由提交者在正式结课报告中填写，不以技术测试记录替代成员贡献说明。

下载仓库时应保留 `.env.example`、`.gitignore` 等点号文件。源码包命令为：

```powershell
.\.venv\Scripts\python.exe scripts/package_release.py dist/meme-studio-source.zip
```

备份实际编辑项目时，需另外按安装说明保存本机数据库和资产目录；公开演示媒体不包含可恢复的私人项目数据库。
