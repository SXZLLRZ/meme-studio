
# P7 整合验收与交付

## 已验证路径

1. 将 P4 合成原图、实际局部编辑结果与对应历史复制到隔离的验收目录。通过 Chinese-CLIP 在三张合成图中检索，正确图片排在首位，重开索引新增编码为 0。
2. 对照已保存的历史蒙版检查原图和 P4 结果。选区内发生变化，选区外原像素一致，生成结果版本清空旧选区。
3. 在静态版本保存两份配字分支，验证撤销、旧版恢复、底图 ID 和 PNG 缓存。PNG 实际打开验证为 1024×1024。
4. 通过模拟视频平台从同一静态锚点创建任务，重建任务服务后沿用原任务 ID。保存本机无字视频再配字，解码验证 MP4 和 GIF，重复导出命中缓存。
5. 两个页面会话各保存第一角，最终蒙版只使用本会话提示点。并发产生新版本时，另一页用旧版本保存被拒绝。
6. 经用户授权，从同一 P4 静态结果真实生成一段 720P、3 秒、无声视频。重开任务服务后按原平台 ID 查询并保存，约 22.1 秒。打开导出结果确认 H.264 MP4 为 960×960、90 帧，GIF 为 512×512、36 帧且普通循环。两者重复导出均复用缓存。
7. 经用户授权发起一次 Qwen-Plus 纯文字复测，成功返回检索「橘猫」与编辑「给它加墨镜」。本阶段新增真实调用为文字 1、图片 0、视频 1。
